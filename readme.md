# Лендинг «Тимон ищет дом»

Одностраничный лендинг Тимона (5,5 месяца, метис немецкой овчарки) из приюта «Зов предков».
Цель: привести к звонку именно за Тимоном.
Телефоны: **Оля 8-967-060-25-73** (главный, акцентный) и Вика 8-903-588-86-72 (второй).

**Версия:** v1.2 (12.09.2026). Главный принцип: **страница ничего не обещает, чего нет**.
Честный возраст, честные фото (свежие, сентябрь 2026), честная история (дважды возвращался),
честный скрипт звонка — всё ради того, чтобы человек доехал в приют именно к Тимону.

## Как открыть

Локально: просто откройте `index.html` в браузере (двойной клик). Никаких сборок и зависимостей
нет — это чистый статический сайт (HTML + CSS + vanilla JS).

Онлайн: сайт разворачивается в Function Compute (окружение nginx). Формальная публикация на домен —
кнопкой **Publish** в интерфейсе AutoClaw (пользователь). В сессии 12.09.2026 авто-публикация была
недоступна (`Website Delivery is not enabled for this task`), поэтому `projects/projects.json` не менялся.

## Где что менять

- **Возраст:** фраза «5,5 месяца» встречается в `index.html` 10 раз (title, meta, OG, hero, галерея, «почему ждёт», скрипт звонка). Меняется поиском по `5,5 месяца`.
- **Тексты:** всё в разметке `index.html`, отдельных файлов с контентом нет.
- **Цвета:** переменные в начале `css/style.css` (`--terra`, `--paper`, `--ink` и др.).
- **Телефоны:** ищутся по `tel:` в `index.html` — верхняя панель, hero, шаг 1, финальный CTA, мобильная панель, блок «О приюте». Акцентный номер — Оли (`tel:+79670602573`): он в шапке (кнопка `btn-primary`), в hero, первым в шаге 1 (класс `btn-primary`) и первым в финальном CTA; у кнопки Вики в финальном CTA класс `is-secondary` (контурная). Чтобы поменять приоритет — поменяйте местами `btn-primary` и `btn-call`/`is-secondary` и порядок кнопок.
- **Фото:**
  - `img/hero.jpg` — главное фото (квадрат 1:1, кадрируется от верха: `object-position: 50% 0%` в `.hero-photo img`). Дублируется в `img/og.jpg` — это превью для соцсетей (`og:image`).
  - `img/g1–g4.jpg` — «было»: Тимон в 2,5 месяца.
  - `img/snew1–snew5.jpg` — свежие фото (сентябрь 2026). В галерее используются snew1, snew2, snew3, snew5; snew4 стоит главным фото (скопирован в `hero.jpg` и `og.jpg`).
  - `img/new1–new3.jpg` — архив (август 2026), на странице больше не используются, можно удалить.
  - `img/story.jpg` — фото для блока истории.
  - **Важно:** если новое главное фото не квадратное, при необходимости подправьте `object-position` у `.hero-photo img`.
  - **Грабли, из-за которых галерея «расползалась»:** у `<img>` в разметке есть атрибуты `width`/`height`.
    Они работают как CSS-высота и перебивают пропорции `aspect-ratio` — плитки вырастали до 246×1746 px.
    Спасение — обязательный `height: auto` в правилах `.g-item img`, `.story-photo img`, `.hero-photo img`.
    При добавлении новых картинок этот `height: auto` трогать нельзя.
  - **Телефоны в шаге 1** свёрстаны как `.call-lines` (имя и номер в две строки) — так номер никогда не
    рвётся посередине («8-903-588-» / «86-72»).
- **Видео:** сейчас нет. Если появится — проще всего вставить его в секцию после hero: `<video controls playsinline src="img/timon.mp4" poster="img/hero.jpg"></video>`; `timon.mp4` положить в `img/`. Секция с видео была удалена в v1.2, чтобы не висел пустой плеер.
- **Адрес/гео:** секция «Как забрать», шаг 2.
- **SEO:** `<title>`, meta description, OG-теги и canonical (домен sobakasobaka.ru) — в `<head>` `index.html`.

## Деплой-контракт (Function Compute, nginx)

- Это **управляемая статика**: AutoClaw сам упаковывает и загружает файлы. Агент не пишет `nginx.conf`
  (авторский конфиг отбрасывается), не вызывает API Function Compute и не знает адрес превью заранее.
- **Сайт-рут = папка, где лежит `entryFile`** — то есть корень проекта (`index.html`). Всё, что лежит ниже,
  уходит на сервер; `.git` исключается автоматически. Поэтому `readme.md` и `moderation-checklist.html`
  тоже публикуются — если это не нужно, их стоит держать вне папки проекта.
- Только статика: HTML/CSS/JS/картинки. Никакого SSR, API, баз данных и процессов.
- Лимиты: 5000 файлов и 100 МБ исходников (наш проект — ~5 МБ).
- Публикация на домен — кнопкой Publish у пользователя; превью-ссылку присылает система.

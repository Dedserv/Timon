# Лендинг «Тимон ищет дом»

Одностраничный лендинг щенка Тимона (4 месяца, метис немецкой овчарки) из приюта «Зов предков».
Цель: влюбить посетителя и довести до звонка кураторам (Вика 8-903-588-86-72, Ольга 8-916-793-62-20).

## Как открыть

Локально: просто откройте `index.html` в браузере (двойной клик). Никаких сборок и зависимостей нет —
это чистый статический сайт (HTML + CSS + vanilla JS).

Онлайн: сайт автоматически разворачивается в Function Compute (окружение nginx) — превью-ссылка
приходит после обновления `projects/projects.json`. Формальная публикация на домен — кнопкой
**Publish** в интерфейсе AutoClaw (пользователь).

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Единственная страница (hero → характер → история → галерея → «он готов» → «как забрать» → финальный CTA) |
| `css/style.css` | Вся стилизация: «тёплый дневник», адаптив, анимации |
| `js/main.js` | Появление блоков при скролле + лайтбокс галереи |
| `img/` | Фотографии (подготовлены из workspace\projects\photo) |
| `nginx.conf` | Конфиг для Function Compute (nginx, порт 9000, /tmp-пути) — не трогать |

## Где что менять

- **Тексты:** `index.html` — вся копирайтерская часть в разметке (заголовки, описания, подписи).
- **Цвета:** переменные в начале `css/style.css` (`--terra`, `--paper`, `--ink` и др.).
- **Фото:** положить новые файлы с теми же именами в `img/` (hero.jpg, g1–g4.jpg, story.jpg, new1–3.jpg) — сайт подхватит автоматически. Оригиналы фото лежат в `workspace\projects\photo`.
- **Телефоны:** ищутся по `tel:` в `index.html` (два места: шаг 1 и финальный CTA) + верхняя панель + мобильная панель звонка.
- **Адрес/гео:** секция «Как забрать», шаг 2.
- **SEO:** `<title>`, meta description, OG-теги и canonical (домен sobakasobaka.ru) — в `<head>` `index.html`.

## Деплой-контракт (Function Compute, nginx)

- В корне проекта обязателен `nginx.conf` (есть): `listen 9000;`, `root /code;`, `daemon off;`, все temp-пути в `/tmp`.
- `index.html` — точка входа; файлы должны лежать в корне zip рядом с `nginx.conf` (без вложенной папки).
- Ограничение размера zip: 50 MB (у нас ~1.2 MB — запас большой).
- API Function Compute не вызывается агентом — создание/загрузка/публикация выполняются контролируемым модулем AutoClaw Main и пользователем.

## Яндекс.Метрика (аналитика и цель «звонок»)

Чтобы видеть трафик и оптимизировать Директ под звонки, установи счётчик Метрики:

1. Создай счётчик: https://metrika.yandex.ru → «Добавить счётчик» → получи номер вида `XXXXXXXXX`.
